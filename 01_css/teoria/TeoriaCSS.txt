CSS
----
Cascade Style sheet
 
Declaramos un conjunto de estilos, que se aplicaran a los elementos que se definen en HTML.

Modos de trabajo
-----------------

1.Dentro de la etiqueta head
<style>
</style>

2.Dentro de la propia etiqueta HTML
<body>
	<p style=""></p>
</body>

3.Definir los estilos en un documento externo, .css, dentro de la etiqueta head, incrustamos el archivo.

<head>
	<link rel="stylesheet" href="estilo1.css">
</head>

CONCEPTO DE REGLA
------------------
Una regla css, se utiliza para declarar una serie de propiedades, con sus valores y aplicarlo a los elementos HTML

Sintaxis:
		tiporegla
		{
		propiedad:valor;
		}

TIPOS DE REGLAS
-----------------

1.Regla ID, los formatos que declaramos dentro, se aplican exclusivamente, al elemento del documento HTML que tiene esa id.(MAYOR PRIORIDAD EN CASO DE COINCIDIR CON OTRAS REGLAS)

Sintaxis:
		#nombreid
		{
		propiedad:valor;
		}

<body>
	<p id="p1"></p>
</body>

2.Regla de clase, se define para aplicar los estilos a varios elementos de diferente naturaleza. Si queremos aplicar la regla de clase, necesitamos añadir el atributo class, en HTML

Sintaxis:
		.nombreclase
		{	
		propiedad:valor;	
		}

En HTML:	
		<body>
		<p class="nombreclase">
	
		</body>

3.Regla por etiqueta. Modificamos los estilos de todos los elementos que se declaran con esa etiqueta.

Sintaxis:
		p
		{
		propiedad:valor;
		}

PRIORIDAD
---------
1.ID
2.Clase
3.Etiqueta
